# 固定插画生成提示词

把方括号变量替换为照片中的实际内容。此提示词用于生成右侧插画；左侧照片裁切与最终签名由脚本处理。

```text
任务类型：照片转固定风格插画。

输入图片角色：
- 图片 1 是已经裁切为 3:4 的用户照片，也是人物身份、姿态、服装、关键物品和构图的唯一依据。
- 风格板与系列锚点仅为风格参考。只提取共同的抽象视觉语言，不复制其中的人物、古装、帽子、动物、道具或场景。
- 颜色规范图的上半部分是背景基底色 #FDFCFC，下半部分是亚洲人物皮肤基底色 #FFF1DF。只使用颜色，不得复制分割线或色块形状。

主要人物：
[填写人物数量、年龄感、发型、面部识别特征、服装、配饰、姿态、动作、视线，以及人物正在手持或直接使用的关键物品。]

严格保持图片 1 中的人物数量、身份线索、相对位置、身体朝向、姿势、动作、视线、表情和人物关系。保留脸形、发型、发色、年龄特征、眼镜、胡须、服装轮廓、服装基本颜色、配饰，以及人物正在穿戴、手持或直接使用的关键物品。不要虚构照片中不可见的身体部分。

将真实五官温和简化为朴拙插画语言：小而自然的点状眼睛或短小眼线、极简鼻线和微小的低饱和珊瑚红嘴唇。通过脸形、发型、服装、配饰、姿态和动作保持可辨识度，不夸张美化，不改变年龄和人物气质。

完整移除原照片背景。删除建筑、墙面、窗户、窗帘、天空、植物、车辆、家具、床铺、沙发、桌椅、地面、路人、装饰、文字、线缆、散落物品和其他环境信息。只保留人物、人物穿戴物，以及人物正在手持或直接使用的关键物品。不得添加椅子、地面线、投影或用于填补空白的装饰。

固定画风：温柔、安静、朴拙、童真而克制的纸本生活叙事插画。造型简洁概括，比例自然中略带稚拙感，不使用 Q 版、大头或夸张大眼睛。黑色或深褐色手绘轮廓松弛、圆润，带轻微自然抖动和不完全均匀的粗细；减少内部结构线，避免光滑机械的矢量轮廓。头发表现为简洁、饱满的深色色块，只保留极少量发丝。

绘画材质：不透明水彩、水粉、蜡笔和干性彩铅混合的纸本质感，以宽大平涂色块为主。色块边缘轻微软化并略有不规则，保留细腻干笔纹理和颜料颗粒。减少衣褶、鞋子和物品的写实细节；没有数码渐变、塑料光泽、强烈高光、复杂体积感或电影式灯光。

固定配色：低饱和、柔和、温暖、略带复古感。优先使用墨黑、深褐、灰蓝、雾霾蓝、靛青、鼠尾草绿、淡薄荷绿、柔和鹅黄、赭石、杏色、珊瑚红、砖红和少量灰紫。每幅控制在约 5～7 种主要颜色。保留照片中服装和关键物品的基本色相，同时适度降低饱和度。

亚洲人物肤色：当照片人物明确为亚洲人时，所有裸露皮肤统一使用 #FFF1DF，RGB（255,241,223）。面部、额头、耳朵、脖子、锁骨、胸口、手掌、手指、手臂、脚踝和其他裸露皮肤不得出现色相、明度或饱和度差异。皮肤使用干净的单色平涂，不添加写实阴影、高光、渐变、反光、环境染色、腮红扩散或水彩晕染。只允许极轻微且均匀的纸面颗粒。画面中有多位亚洲人物时也全部使用同一基底色。非亚洲人物保留其原本基本肤色和族裔特征。

固定背景：背景基底色为 #FDFCFC，RGB（253,252,252）。只加入非常轻微、细腻、干净且均匀的天然纸张纹理；纸纹低对比、低密度，缩小观看时仍接近统一的 #FDFCFC。不得出现明显噪点、污渍、折痕、破损、泛黄、斑驳、水彩晕染、渐变、光晕、阴影、落地影、地面线、边框或装饰。

签名预留：最终成品会在后处理中加入一个手写签名。本次生成不要输出签名、文字、乱码、Logo 或水印。在不改变人物构图的前提下，尽量保留至少一处不遮挡主体的小块空白区域，优先右下角，其次右上角、左下角或左上角。

构图：3:4 竖版。严格沿用图片 1 已经确定的裁切、人物比例和姿态。完整保留裁切图中可见的头顶、双手、双脚和关键物品，不重新摆姿势，不拉伸人物。

输出：只生成一张独立的 3:4 插画，不生成原图对比、不生成左右拼图，不添加文字、签名、标题、Logo、水印或边框。

反向约束：避免照片写实、超写实皮肤、3D 渲染、动漫、漫画、Q 版、夸张大眼睛、潮玩、商业吉祥物、光滑矢量插画、机械描边、油画厚涂、塑料质感、强烈光影、数码渐变、霓虹色和高饱和配色。不要改变人物数量、身份、年龄、脸形、发型、服装、姿势、动作、视线或人物关系。避免身体扭曲、双手变形、手脚缺失、额外肢体、额外手指、手指粘连、重复人物、错误遮挡、错误交互和错误裁切。不要保留或重建原照片背景。亚洲人物不得出现脸、耳朵、脖子、双手和其他裸露皮肤颜色不一致；避免脸白手黄、脸粉脖子灰、局部橙色、局部棕色、灰色阴影、肤色渐变和多种肤色色块。背景不得粗糙、做旧、泛黄、脏污或斑驳。不得生成任何文字或签名。
```
